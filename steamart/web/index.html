    Desktop shortcut

    Add SteamArt to your application menu and desktop so you can start it with a double-click instead of the terminal.

    How this works

    • Shortcuts are written to userdata/<id>/config/shortcuts.vdf; a timestamped backup is kept beside it each time.
    • Artwork lands in userdata/<id>/config/grid using the app ID Steam derives from the executable path plus the game name.
    • Close Steam before importing. Steam rewrites these files when it exits and will undo changes made while it is running.
    • Restart Steam afterwards to see everything.
